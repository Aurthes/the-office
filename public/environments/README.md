# Environment lighting

`potsdamer_platz_1k.hdr` is the same environment map used by Drei's `city`
preset. It is served locally so the office and avatar preview do not depend on
an external asset CDN at runtime.

- Asset: [Potsdamer Platz](https://polyhaven.com/a/potsdamer_platz), by Greg Zaal.
